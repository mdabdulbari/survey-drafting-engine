# Agent Guidelines for survey-drafting-engine

## Core Priorities

1. **High Performance** - Prioritize speed, efficiency, and optimization. Profile code and optimize hot paths. Minimize bundle size and runtime overhead.

2. **Product Grade Quality** - Write production-ready code. No quick hacks or technical debt. Focus on reliability, maintainability, and correctness.

## Commit Guidelines

- **Do NOT add Claude as co-author** in commits. All commits should be authored by Abdul Bari only.
- Use clear, descriptive commit messages that explain the "why" behind changes.
- Keep commits focused and atomic when possible.

## Code Standards

- Write clean, well-structured code that follows the project's existing patterns.
- Prefer explicit over implicit - clarity beats cleverness.
- Optimize for readability and maintainability alongside performance.
- Remove unused code and dependencies completely rather than hiding them.
